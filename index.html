核心技术 · Core

没有录音权限，律动也要跟得上音乐

旧做法用「歌曲 hash → 固定 BPM + 正弦波」合成动画，与正在播放的声音没有任何数据联系，节奏必然对不上。现在用 MediaCodec 解码同一份音频，算出 32 段能量随时间的变化，播放时按真实进度查表回放 —— 不启用麦克风、不录音、不联网二次拉流。

四级自动降级 · 「关于」页可实时查看当前数据源

FFT 窗 1024、步长 512（50% 重叠）、32 段分频；长音频逐 hop 做 FFT 并逐段取峰值合并，避免跳帧漏掉整击鼓点。切歌 / seek 立即对齐，节奏表量化后缓存在本机。

开始使用 · Get started

两种方式，都是装上就用

① 直接安装

下载 v2.3.4 debug 包（约 594 KB），在 Android 4.4+ 设备安装。首次启动需阅读并同意《学习免责协议》，之后可在「我的 · 关于」复查。

侧载提示：在荣耀 / 华为 / 小米等 ROM 上若显示「无网络」，先到「系统管家 → 流量管理 → 应用联网」为该应用勾选移动数据与 WLAN，并关闭省流量模式与电池优化。这是系统侧管控，不是 App 兼容性问题。

② 自行编译

需要 JDK 8 + Android SDK Platform 28 + Build Tools 28.0.3，AGP 3.5.3 / Gradle 5.6.4。

# clone / unzip the source
cd MurielMusic
gradle assembleDebug
adb install -r \
  app/build/outputs/apk/debug/app-debug.apk

# older Gradle native lib issue?
gradle -Dorg.gradle.native=false assembleDebug
